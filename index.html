SOC Shift

You're the security analyst on duty. Alerts arrive one at a time. Some are real attacks, some are harmless. Decide what to do before the clock runs out.

How it works

1. Read the alert — a plain-English story plus the raw log.
2. Pick one action: Safe, Suspicious or Attack.
3. Answer before the timer runs out — faster correct answers score more.
4. Stuck? Use a hint. Win streaks add bonus points.

No experience needed — every answer explains what really happened, so you learn as you play. 8 alerts per shift, a few minutes.

Choose your difficulty

Shorter timers also raise the cost of hints.

All data is simulated. IP addresses use reserved example ranges. Nothing here touches a real network.
